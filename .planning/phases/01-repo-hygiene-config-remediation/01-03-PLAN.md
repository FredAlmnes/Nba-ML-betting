<env_var_name_decision>
**The env var name is `ODDS_API_NOKKEL` (ASCII), not `ODDS_API_NØKKEL`.**

CONTEXT.md D-01 and the CONVENTIONS Norwegian-identifier rule suggested `ODDS_API_NØKKEL` "or similar" and left the exact name to Claude's discretion. Verified this session: neither `bash` nor `zsh` can set or unset an environment variable whose name contains `Ø` — `export ODDS_API_NØKKEL=x` fails with `not a valid identifier` in bash and `not valid in this context` in zsh. That would make the variable settable only through a `.env` file, breaking shell export, cron/launchd env blocks, and the missing-key verification command written into `01-VALIDATION.md`.

Resolution: the **environment variable** is ASCII `ODDS_API_NOKKEL` (still Norwegian, transliterated). The **Python identifier stays `API_NØKKEL`**, preserving the codebase's Norwegian-identifier convention where it actually applies. All user-facing messages stay in Norwegian. Record this deviation in the SUMMARY.
</env_var_name_decision>
