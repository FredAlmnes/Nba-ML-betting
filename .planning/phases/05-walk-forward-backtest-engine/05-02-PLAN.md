<objective>
Extract the train/calibrate/persist/load logic out of `03_tren_modell.py` into a new
`model.py` that is `as_of`-aware, so the one-shot training script and plan 05-07's
walk-forward retrain loop run the *same* code instead of two drifting copies.

This is the last duplicated-decision-logic gap left in the codebase (05-CONTEXT.md
"Package & Module Structure", 05-RESEARCH.md Anti-Pattern 2). It matters more here than
in Phase 2's extractions because the duplicated thing would be the *calibration split
discipline*: Phase 3 closed a real leakage bug (CALIB-01) by making tren/kalibrer/test
disjoint, and a hand-written second training path inside `backtest.py` could silently
reopen it inside the walk-forward loop where nobody would see the reliability numbers.

`model.py` therefore carries both split shapes behind one contract:
`as_of=None` → 3-way tren/kalibrer/test via the already-tested
`kalibrering.del_kronologisk_3veis` (one-shot reporting, 03's existing behaviour);
`as_of=<dato>` → 2-way tren/kalibrer over rows strictly before `as_of`, sized by a
*fraction* of the expanding window rather than a fixed month count (05-RESEARCH.md
Pattern 3 + Assumption A5 + Pitfall 4 — a fixed 1-month calibrate window has ~50 games
in Nov 2022, well below the 172-row set Phase 3 already found too small).

Purpose: BT-01 needs one training implementation the walk-forward replay can call per
retrain point; BT-02 needs that implementation to be provably `as_of`-strict.
Output: `model.py`, `tests/test_model.py`, a rewired `03_tren_modell.py` whose stdout is
byte-identical to today's, and retargeted source guards.
</objective>
