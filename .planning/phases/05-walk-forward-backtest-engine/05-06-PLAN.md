<objective>
Make the injury filter backtestable: add a date-driven season-boundary helper and an
as-of-aware team-health check to `skadefilter.py`, reading plan 05-05's
`nba_spillerlogg_raw.csv` instead of a live `nba_api` call, and extend
`tests/test_skadefilter.py` with the leakage-safety proof.

`05-CONTEXT.md`'s Post-Research Resolution put this in scope rather than disabling the
injury filter in the backtest: BT-01 names the injury filter as part of the replayed
decision pipeline, and disabling it would bias every reported ROI in an unknown direction
(games where a key player was actually out would be scored as if they weren't). Plan 05-05
closed the data half of that gap by producing `nba_spillerlogg_raw.csv`. This plan closes
the logic half.

The live filter is clock-driven in two places a backtest must not inherit:
`gjeldende_sesong()` reads `datetime.now()` (`skadefilter.py:46-47`), and
`LeagueDashPlayerStats(last_n_games=3)` means "the 3 most recent games as of when the API
is called." Both are replaced here by parameterized, date-driven equivalents. The live
functions themselves are left byte-identical — `06_bot.py` still needs them unchanged.

This plan's negative-control test is the injury filter's half of BT-02, structurally
parallel to `tests/test_parity.py::test_grenserad_paa_as_of_er_ekskludert`, which already
proves the same property for `features.py`.

Purpose: without this, BT-01's "full decision pipeline" claim is unbackable and plan
05-07's walk-forward loop has no injury stage to call.
Output: five new helpers plus `sjekk_lag_helse_som_of()` in `skadefilter.py`, and 13 new
no-network tests appended to `tests/test_skadefilter.py`.

```python
ANTALL_TOPPSPILLERE = 3     # Sjekk de N viktigste spillerne per lag

def sjekk_spiller(siste3, spiller_id, spiller_navn, sesong_min):
    """Sjekker om spilleren er i siste-3-kamper-datasettet med et fornuftig antall minutter."""
    siste = siste3[siste3["PLAYER_ID"] == spiller_id]
    if siste.empty or siste["GP"].iloc[0] == 0:
        return False, f"{spiller_navn} ({sesong_min:.0f} min/kamp) – 0 kamper siste 3"
    gp = siste["GP"].iloc[0]
    min_snitt = siste["MIN"].iloc[0]
    if gp < 2 or min_snitt < 10:
        return False, f"{spiller_navn} ({sesong_min:.0f} min/kamp) – kun {gp} kamp(er), {min_snitt:.0f} min"
    return True, f"{spiller_navn} ({sesong_min:.0f} min/kamp) – {gp} kamper, {min_snitt:.0f} min"
```
