Verified endpoints and costs (04-RESEARCH.md, from the raw official docs):
| Endpoint | Cost |
|---|---|
| `GET /v4/sports/{sport}/odds` (live) | 1 x markets x regions |
| `GET /v4/historical/sports/{sport}/odds` (sport-wide snapshot, ALL games at that timestamp) | 10 x markets x regions **per call** |
| `GET /v4/historical/sports/{sport}/events` (discovery, no odds) | 1 per call, 0 if empty |
| `GET /v4/historical/sports/{sport}/events/{id}/odds` (per-event) | 10 x markets x regions **per event** — NOT used, see D-03 amendment |

Response headers on every call: `x-requests-last` (this call's cost), `x-requests-remaining`, `x-requests-used`.
Rate limit: 30 requests/second on paid plans.

Existing pattern this replaces (`04_value_detector.py:64-85`) — behaviour to preserve exactly:
