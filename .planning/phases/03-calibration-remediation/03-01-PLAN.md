Behavior (per D-03 — bisect the EXISTING 2-month holdout, do not widen it):
1. Raise `ValueError` with a Norwegian message if `kalibrer_cutoff_mnd >= tren_cutoff_mnd` — otherwise the kalibrer-window is empty or inverted and the caller would silently get zero calibration rows.
2. `maks_dato = df[dato_kolonne].max()`
3. `fra_dato  = maks_dato - pd.DateOffset(months=tren_cutoff_mnd)`
4. `midt_dato = maks_dato - pd.DateOffset(months=kalibrer_cutoff_mnd)`
5. `tren_mask     = df[dato_kolonne] <  fra_dato`
6. `kalibrer_mask = (df[dato_kolonne] >= fra_dato) & (df[dato_kolonne] < midt_dato)`
7. `test_mask     = df[dato_kolonne] >= midt_dato`
8. `return tren_mask, kalibrer_mask, test_mask`

The three boundary comparisons MUST use `<`, `>= / <`, `>=` exactly as above so the masks are mutually exclusive and jointly exhaustive — this is the property the Task 2 tests assert.

Docstring: short Norwegian, stating the return contract "tre boolske masker (tren, kalibrer, test) som aldri overlapper og til sammen dekker alle rader". Add a Norwegian comment above the `midt_dato` line noting that `test` er den nyeste halvdelen og aldri skal brukes til fitting (D-03/D-04).

No prints, no file reads, no type hints (project convention). Norwegian identifiers and comments throughout.
