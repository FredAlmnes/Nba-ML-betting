<objective>
Rewire `03_tren_modell.py` onto the three-way chronological split so the isotonic calibrator is fit on data that is disjoint from both the training data and the final evaluation slice, and report the reliability diagram exclusively from the untouched `test` slice.

Purpose: This is the actual CALIB-01/CALIB-02 bug fix. The current (uncommitted, never-committed) file fits the calibrator with `kalibrerer.fit(y_rå, y_test)` where `y_rå` came from `X_test`, and then evaluates calibration quality on that same `X_test`/`y_test` — the confirmed same-slice leakage. It also points XGBoost's `early_stopping_rounds` `eval_set` at `(X_test, y_test)`, letting the final test slice steer how many trees get built (D-04). After this plan, `test` appears only inside `predict`/`predict_proba`/metric calls — never inside any fitting call.

Output: A corrected `03_tren_modell.py` whose console output makes the fit/eval separation visually obvious ("kalibrert på X, evaluert på Y", D-06), plus source-level guard tests so the bug cannot silently reappear.
</objective>
