## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator command line → `kjor_backfill` | A typo here is the only realistic path to burning the month's budget in one run |
| The Odds API → permanent archive | Fetched rows become the ground truth Phase 5's backtest trusts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-20 | Denial of service | Runaway loop exhausting the 20,000-credit month | mitigate | Mandatory `--maks-kreditt` with no default, ceiling re-checked before every single call, `break` (not `continue`) on breach |
| T-04-21 | Denial of service | Accidental full run from a mistyped command | mitigate | Dry run is the default; `--utfor` must be passed explicitly; the API key is not even read without it |
| T-04-22 | Tampering | Duplicate spend on an already-archived date | mitigate | `er_allerede_arkivert` runs first in the loop body, before any network call; enforced by `test_er_allerede_arkivert_hindrer_dobbelt_kall` |
| T-04-23 | Tampering | A later cluster's snapshot overwriting an earlier cluster's true closing line | mitigate | `kun_event_ider` restricts each closing call's rows to its own cluster; clusters processed in chronological order |
| T-04-24 | Repudiation | No evidence of what a long run actually cost | mitigate | `logg_kreditt` per call plus a printed summary; `kreditt_logg` is queryable after the fact |
| T-04-25 | Denial of service | One bad date aborting a 480-date paid run | mitigate | Per-date `try/except Exception` continues to the next date; `SystemExit` deliberately not caught so fatal auth/param errors still stop the run |
</threat_model>
