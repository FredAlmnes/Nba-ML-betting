  <action>
    Append to `odds.py`, same Norwegian/snake_case/no-type-hints style. Write the tests in `tests/test_odds.py` first, then implement.

    Import `from zoneinfo import ZoneInfo` (stdlib, Python 3.9+; this repo runs 3.14.3) and define `NBA_TIDSSONE = ZoneInfo("America/New_York")` with a Norwegian comment explaining that NBA schedule dates follow the home arena's local calendar day, which is why a raw UTC date slice is wrong.

    `kamp_dato_fra_commence(commence_time)`: parse the ISO8601 string (the API returns a trailing `Z`; `datetime.fromisoformat` in Python 3.11+ accepts `Z`, but normalise `Z` to `+00:00` anyway so the function does not silently depend on interpreter version), `astimezone(NBA_TIDSSONE)`, return `.date().isoformat()`.

    `morgen_tidspunkt(kamp_dato)`: return `f"{kamp_dato}T13:00:00Z"`. The docstring must state, in Norwegian and explicitly: 13:00 UTC is 08:00 EST / 09:00 EDT, i.e. the morning of game day in the arena's timezone and before every NBA tipoff; this is the operationalisation of D-01 and must stay identical to whatever time the live bot is actually scheduled to run — if that schedule ever changes, this constant changes with it or the whole backtest premise breaks (assumption A3 in 04-RESEARCH.md). Define the hour as a module constant `MORGEN_UTC_TIME = 13` rather than inlining the number, so there is one place to change it.

    `snap_til_5min(tidspunkt)`: accept either a `datetime` or an ISO string, floor the minute to a multiple of 5, zero the seconds and microseconds, and return an ISO string ending in `Z` (format `%Y-%m-%dT%H:%M:%SZ`). Flooring, never rounding — rounding up can push a "closing" snapshot past tipoff, which is exactly Pitfall 4.

    `grupper_commence_tider(events, maks_gap_minutter=60)`: accept either a list of commence_time strings or a list of event dicts each carrying a `commence_time` key (the discovery endpoint returns dicts). Normalise to sorted unique timestamps, then walk them, starting a new cluster whenever the gap to the current cluster's first timestamp exceeds `maks_gap_minutter`. Return a list of lists of the original ISO strings. Docstring: NBA slates commonly span 3+ hours of tipoff windows on one date, so a single per-date closing snapshot cannot be "just before tipoff" for every game (Pitfall 4).

    `lukketidspunkt(klynge, minutter_for=15)`: take the earliest timestamp in the cluster, subtract `minutter_for` minutes, pass through `snap_til_5min`, return the string.

    Add these tests to `tests/test_odds.py` under a clear Norwegian section comment. Every value must be a literal — no `datetime.now()`, no randomness.
